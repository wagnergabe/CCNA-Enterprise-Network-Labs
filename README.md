# CCNA Enterprise Network Labs

Hands-on Cisco networking labs covering VLANs, routing, OSPF, DHCP, ACLs, STP, network services, and enterprise troubleshooting.

This repository documents a series of Packet Tracer labs built to reinforce CCNA-level networking concepts through practical configuration, verification, and troubleshooting.

## Lab Overview

### VLAN Routing
Configured multiple VLANs, access ports, trunks, and router-on-a-stick inter-VLAN routing.

### DHCP & DNS
Configured centralized DHCP services, address pools, default gateways, DNS resolution, and client addressing.

### ACL Security
Implemented access control lists to restrict communication between departments while preserving required connectivity.

### OSPF WAN
Built a multi-router WAN using OSPF area 0, point-to-point links, routed LANs, and neighbor verification.

### STP & Port Security
Configured spanning tree root selection, BPDU Guard, and switch access-port security features.

### Enterprise Capstone
Integrated multiple CCNA technologies into a larger enterprise topology, including:

- VLANs and trunking
- Inter-VLAN routing
- DHCP relay
- OSPF
- ACLs
- DNS
- NTP
- Syslog
- SSH
- CDP / LLDP
- FTP restrictions
- Centralized services
